## Development

This repo uses the [Vite+](https://viteplus.dev) toolchain.

Install dependencies:

```bash
vp install
```

Check, test, and build:

```bash
vp run ready
```

Run the development server:

```bash
vp dev
```

## Documentation

Docs are in the [mango repo](https://github.com/mangowm/mango/tree/main/docs).
