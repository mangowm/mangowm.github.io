## Animation Timing

Controls the duration of each animation type in milliseconds.

### Durations

- **`animation_duration_move`** – Duration of window move/resize animations (1–50000 ms).
- **`animation_duration_open`** – Duration of window open animations (1–50000 ms).
- **`animation_duration_close`** – Duration of window close animations (1–50000 ms).
- **`animation_duration_tag`** – Duration of tag-switch (workspace) animations (1–50000 ms).
- **`animation_duration_focus`** – Duration of focus-change animations (1–50000 ms).
