# Tags

Configure tag navigation behaviour.

## Settings

| Option                  | Default   | Description                                                                   |
| ----------------------- | --------- | ----------------------------------------------------------------------------- |
| `tag_carousel`          | `0` (off) | Tags wrap around — moving past the last tag returns to the first, and v.v.    |
| `view_current_to_back`  | `0` (off) | Viewing the current tag sends it to back and switches to the previous tag.    |
