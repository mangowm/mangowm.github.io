# Idle

Configure inactivity timeouts — screen blanking inhibition and cursor auto-hide.

## Settings

### Screen Blanking

| Option                        | Default   | Description                                                                       |
| ----------------------------- | --------- | --------------------------------------------------------------------------------- |
| `idleinhibit_ignore_visible`  | `0` (off) | Only fullscreen windows may inhibit the idle inhibitor (DPMS/screen blanking).    |

### Cursor

| Option                | Default | Description                                                   |
| --------------------- | ------- | ------------------------------------------------------------- |
| `cursor_hide_timeout` | `0`     | Seconds of inactivity before auto-hiding the cursor (0=never).|
