# Scratchpad

Configure the special scratchpad window — a persistent window that can be toggled in and out of view.

## Settings

### Behaviour

| Option                     | Default   | Description                                                          |
| -------------------------- | --------- | -------------------------------------------------------------------- |
| `single_scratchpad`        | `1` (on)  | Only one scratchpad window at a time. Opening a new one hides the previous. |
| `scratchpad_cross_monitor` | `0` (off) | Scratchpad windows can appear on any monitor, not just the origin.   |

### Size

| Option                    | Default | Description                                                              |
| ------------------------- | ------- | ------------------------------------------------------------------------ |
| `scratchpad_width_ratio`  | `0.8`   | Width of the scratchpad relative to the monitor (0.1–1.0).               |
| `scratchpad_height_ratio` | `0.9`   | Height of the scratchpad relative to the monitor (0.1–1.0).              |
