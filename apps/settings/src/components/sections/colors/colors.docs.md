## Colors

Controls the color scheme used by mangowm for window borders, backgrounds, and indicators.

### Color Fields

| Field | Description |
| :--- | :--- |
| `rootcolor` | Desktop background behind all windows |
| `bordercolor` | Unfocused window border (non-selected monitor) |
| `focuscolor` | Focused window border on the selected monitor |
| `maximizescreencolor` | Border when window is focused and maximized |
| `urgentcolor` | Urgent window border — overrides all other colors |
| `scratchpadcolor` | Border when focused on a scratchpad window |
| `globalcolor` | Border when focused on a toggleglobal window |
| `overlaycolor` | Border when focused on a toggleoverlay window |
| `dropcolor` | Drop-shadow rectangle when dragging floating windows |
| `splitcolor` | Dwindle manual-split guide line |
| `shadowscolor` | Drop shadow color for windows |
