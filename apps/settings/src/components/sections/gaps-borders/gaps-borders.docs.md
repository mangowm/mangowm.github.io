# Gaps & Borders

Control how windows are spaced and bordered.

## Window Gaps

| Option | Description |
|--------|-------------|
| `smartgaps` | Only draw gaps when more than one window is present on the tag (0 or 1). |
| `gappih` | Horizontal gap *between* tiled windows (pixels). |
| `gappiv` | Vertical gap *between* tiled windows (pixels). |
| `gappoh` | Horizontal gap between windows and the screen edge (pixels). |
| `gappov` | Vertical gap between windows and the screen edge (pixels). |

## Border

| Option | Description |
|--------|-------------|
| `borderpx` | Width of the window border in pixels. Set to 0 for borderless windows. |
| `no_border_when_single` | Remove borders when only one window is visible on a tag. |
| `no_radius_when_single` | Remove corner radius when only one window is visible on a tag. |
