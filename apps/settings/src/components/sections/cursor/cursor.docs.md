# Cursor

Configure the XCursor theme and size used by the compositor.

## Settings

| Option         | Description                                                                |
| -------------- | -------------------------------------------------------------------------- |
| `cursor_theme` | XCursor theme name (e.g. `Adwaita`, `Breeze`, `DMZ-White`, `Vanilla-DMZ`). |
| `cursor_size`  | Cursor size in pixels. Range: 16–128.                                      |
